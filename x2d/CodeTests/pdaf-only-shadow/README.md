## 影子判定器输入边界

影子判定器接收统一传感器坐标中的 ROI、规范化置信度及经第一代镜头标定的绝对位置，不假定两代相位区域的布局相同。位置和方向标尺、真实帧同步、Type3 原始字段到 `Zone` 的转换仍未完成，不能直接消费 425 候选的 13 字节记录。

多个区域不一致、低置信、覆盖不足、越界、帧号异常、方向矛盾或运动超限均不生成目标。多帧检查要求至少三个连续且一致的影子帧；阈值来自显式测试输入，不是已移植的二代原厂标定。通过时只有诊断建议，不产生或授权镜头命令。

## 离线复现与依赖

从本目录运行：

```sh
python3 -B -m unittest -v test_pdaf_shadow test_pdaf425 test_pdaf425_adapter
```

Python 3.9+；C 测试需要 C11 编译器，适配器场景还使用地址和未定义行为检查。构建／固件审计的额外依赖及显式路径命令见 [PDAF425.md](PDAF425.md)。默认离线检查只用合成输入，不访问设备、不执行厂商库，也不证明真实合焦质量或实时性能。**只有操作者明确运行实验记录脚本时才会连接设备**；记录方法、依赖和限制见上面的操作说明。

生成物默认留本地，不随源码分发。本目录不收录厂商固件、派生签名或原始设备日志。只读 USB 模块不含参数写入、任意 shell、镜头命令或通用文件传输能力；远程命令使用固定 allowlist，临时日志最多记录 30 秒并按本次 token 清理。

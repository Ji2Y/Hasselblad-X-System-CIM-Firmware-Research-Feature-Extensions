# 自动亮度、桌面界面与退出修正的研究归档

归档：2026-10-16。历史开发：2026-10-04 起。范围：独立 X2D/907 工具包的 0.4.3–0.4.8 阶段；相机侧目标为当时的一代 4.2.0。本文只收录功能行为、来源版本与验证边界，不复制产品安装实现。

## 来源与归属

依据本次对话和独立工具包对应版本的 CHANGELOG 整理。历史公开项目为 [x2d-907-one-click-extension-toolkit](https://github.com/radium-wang/x2d-907-one-click-extension-toolkit)，后续开发仓库为 [hasselblad-one-click-installer-beta](https://github.com/radium-wang/hasselblad-one-click-installer-beta)；后者访问取决于仓库权限。对应版本实现和许可证由独立项目维护，本研究库不重新授权该产品，也不提供其安装、更新或恢复链。

## 自动屏幕亮度：0.4.3

- 在桌面功能展示中增加自动后屏亮度说明，中英文适配。
- 相机扩展页提供启用入口，灰色说明引导至“显示 → 亮度”；说明字号、透明度与间距参考原厂开关描述，并处理英文换行。
- “显示 → 亮度”增加自动亮度开关，用户可独立控制；原亮度项表达为“显示屏最高亮度”。
- 自动调节期间，滑块圆球保留用户设置的上限位置，左侧白色填充跟随实际输出亮度。
- 改用均匀节奏的过渡，减少接近目标时孤立的暗度跳变；原厂输出仍有整数百分比精度，不能承诺完全连续的光学亮度。

后屏环境光输入对应 CM32181，与相机前端 AS7341 光谱白平衡链不同，见[白平衡报告](SPECTRAL-WHITE-BALANCE.md)。上述是产品功能行为及本地实现记录，不是本研究库新完成的相机亮度测量。

0.4.3 历史验证为 144 项带本地输入检查通过；纯源码为 118 项通过、26 项跳过，另有 Qt 6.4.1 亮度／菜单及双语 Mac 桌面检查。物理显示变化、开机和完整恢复验收当时仍待确认；不能把主机检查当作这些实机结果。

## Windows 界面与关闭：0.4.4–0.4.5

0.4.4 将 Windows 视觉布局与 Mac 对齐：白色页面、圆角功能卡、图标、灰色说明、蓝色主操作及统一字体层级；处理逐显示器缩放、较短窗口滚动和键盘焦点可见性。历史 153 项本地检查通过，纯源码为 127 项通过、26 项跳过，另有六种双语布局预览。原生 Windows 显示与缩放仍需单独验证。

用户曾反馈关闭窗口后软件目录仍被占用。0.4.5 针对更新检查任务及软件自有后台进程加入取消、回收和生命周期清理，保留设备操作期间的退出保护，不影响其他应用的进程。历史 166 项本地检查通过，纯源码为 140 项通过、26 项跳过；原生 Windows 退出、移动文件夹及异常退出清理没有被这些检查证明。相机功能载荷与此前版本保持一致。

## 对焦说明与许可证

后续文案移除“不能中途换镜头”的旧提示，把中文“对焦加速 buff”改为“对焦加速”，英文保持对应版本命名；增加旧镜头不建议开启的说明。历史简化文案使用“提高三倍”，不能据此理解为端到端合焦时间提升三倍，也不能覆盖不同请求类型的实际倍率差异。后续三档倍率与验证范围见[对焦更新](AF-EYE-AND-SPEED-UPDATE.md)。

工具包 0.4.3 起采用其专用非商业分发许可证，目标是允许专业摄影使用与免费分享／修改，限制软件出售及未经许可的收费安装。准确授权以对应版本 LICENSE 原文为准；原 MIT 版本和第三方许可保留。本研究库的 MIT 许可没有因此修改。

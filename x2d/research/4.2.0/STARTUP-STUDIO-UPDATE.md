# Hasselblad Startup Studio 与开机页面生命周期

更新：2026-10-12。X2D 固件研究基线为第一代 4.2.0。此前临时 Logo 试验见 [位置分析](STARTUP-LOGO-LOCATION.md) 和 [替换验收](STARTUP-LOGO-REPLACEMENT.md)；新 App 与其旧临时试验是不同阶段。

## 独立应用

[Hasselblad Startup Studio](https://github.com/radium-wang/hasselblad-startup-studio) 已独立发布。提供图片导入、灰度转换、裁剪、原尺寸居中预览、首次备份、连续换图及原厂恢复。研究仓库仅引用其公开来源，不复制应用部署后端、用户图片、原厂库或备份。

macOS Universal 支持 Intel／Apple Silicon。普通 X2D 的实际 App 安装和恢复按钮流程及独立恢复核对通过；Intel 分支通过 Rosetta，本次不能替代真实 Intel 与最低系统验收。首次备份保护、普通／大地身份及显示键保持是应用设计边界；大地版的完整实机流程仍待验收。

应用另增加 907X／CFV 100C 识别与恢复包机型约束，该相关机型的完整实机验收待完成。这里仅记录独立应用范围，不建立该机型的研究实现目录、不复用 X2D 地址或验收。

## Windows 测试版

[0.2.0-preview.2](https://github.com/radium-wang/hasselblad-startup-studio/releases/tag/v0.2.0-preview.2) 提供 Windows x64 自包含测试包。此前云端检查未覆盖真实内置传输程序启动，用户反馈后已复现并修正，补充真实生产启动、协议、退出及原生窗口检查。

历史记录：Windows 云端 132 项检查、真实程序窗口及配套传输程序生命周期通过；本地带固定原厂输入的 171 项离线检查通过，保留 50 个中断恢复点检查。Windows 真实驱动、连接相机及完整安装／恢复未通过本轮实机验收，仍标为预发布测试版。原始用户日志与本地路径不公开。

## 与扩展菜单的生命周期冲突

换图导致界面进程重建时，已有动态菜单入口可能消失；工具包的每次启动仅尝试一次保护阻止当前启动周期再次加载。检查发现公开 0.4.17 与私有 0.5.0 都存在该触发条件，不能仅凭文件目标不重叠判断兼容。正常关机再开机按设计应重新建立入口，但反馈用户尚未完成该项验证；不能宣称已修复。

# X2D 对焦、眼部识别与三档速度进展

更新：2026-10-12。范围：第一代 X2D 100C 4.2.0；记录 2026-10-08 至 10-12 的开发和历史验收。本文不包含设备部署后端、原厂文件或原始设备记录。工具包重构与其他贡献者的新调试框架不属于本次成果。

## AFT 与眼部共存

此前 AFT 人脸区域、连续状态桥接及目标主框显示研究，见 [AFT 报告](AFT-FACE-TRACKING-RESULTS.md)。新候选增加独立的“追踪自动对焦”安装选择、四宫格对焦模式及 AF-T 图标；开启功能只增加可用模式，不自动改变用户当前对焦模式。

共存规则以实际选中的模式为准：选中 AFT 时暂停眼部运行和显示，保留已保存的眼部选择；切回 AF-S／AF-C 时只恢复仍保存为开启的选择。在 AFT 中手动关闭眼部，切出后不会误开。总开关关闭及恢复原状取消对应开启意图。

**历史实机与用户反馈：**独立相机候选完成安装、重启、默认关闭状态、模式切换及恢复核验。用户确认 AFT 面部追踪、AF-S／AF-C 眼部恢复、四宫格图标和取景 AF-T 尺寸；只读状态核对与保存选择一致。保存重启试验确认选中 AFT 后眼部保持暂停，随后完整恢复和原厂重启核验通过。以上未量化眼部合焦准确率、镜头持续追踪成功率、弱光性能或所有镜头兼容性。

**软件整合：**私有 0.5.0 内测增加可选 AFT，五项功能对应 31 种有效安装组合。历史精确输入本地回归 280 项通过；纯源码导出 237 项通过、43 项因缺少私有输入跳过。该数字属于当时完整工具包，本研究库没有复制其部署实现或完整测试输入，不能在本库重建这些软件验收。

眼部功能从临时运行开关推进到可选安装、选择保存及统一恢复。开发中修复了内存对象定位、辅助程序标记误判、未写入对象阻止恢复及未就绪状态被报告为成功等问题。初期版本曾出现灰色开关和恢复失败，后续受保护恢复及原厂重启核验通过；不能将失败版本的旧验证记录当作最终版本通过。

## 公开三档速度

公开工具包 [0.4.17](https://github.com/radium-wang/x2d-907-one-click-extension-toolkit/releases/tag/v0.4.17) 于 2026-10-10 提供 Mac／Windows 包。第一代 X2D 的三档电机控制倍率如下；Type 0／1／2 是原厂请求类型，不是镜头型号分类。

| 档位 | Type 0 | Type 1 | Type 2 |
| --- | ---: | ---: | ---: |
| 低 | 1.5 | 1.5 | 1.5 |
| 中（默认） | 2.5 | 2 | 1.5 |
| 高 | 3 | 3 | 2 |

使用原厂纵向滚动选择器和橙色高亮；关闭加速时选择项灰色不可用，关闭／重启保留所选档位，恢复原状清除选择。保留原厂动态修正、限幅和回退原则。较低倍率提供较温和的选项，但这些倍率不是整体合焦时间提升、光学效果或镜头安全保证。

历史本地检查包括 215 项回归、4,206 个机器码场景、14 种恢复场景及原厂 Qt 选择器检查。机身触控／GPU、原生 Windows／相关机型及光学量化仍有待完成；不把桌面替身测试写成实机结果。完整实现与许可证由独立工具包维护，本库记录研究结论。

## 最新 Windows 内测修正

0.5.0 像素位移整合包的 Windows 测试版 4 于 2026-10-12 在本地完成。已复现追踪开关点击在后台状态读取期间被丢弃的问题，改为用户命令优先、写入串行、迟到回执无效，并保留实际状态确认。历史记录为 343 项本地回归及 95 项解压包检查通过，像素位移计时和提示音保持测试版 3 字节。

这是未公开的本地测试包；Windows 原生运行、驱动和相机操作仍待验证。另一项用户反馈的启动配置核验拒绝尚未确诊，没有降低严格核验或宣称问题已解决。各阶段包的记录不能互相替代。

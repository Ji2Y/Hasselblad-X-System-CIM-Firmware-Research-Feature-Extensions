# X2D II AF-S：遮挡 LiDAR 后仍能对焦的路径

日期：2026-10-04。对象为 X2D II 100C 1.3.16.2。本文直接核对已解包固件的 `lib64/libaaa.so` 与 `etc/aaa/af/af_imx861.json`；不把第一代 4.2.0 地址用于二代。用户报告遮挡 LiDAR 后依然准确，本轮没有连接二代、读取其运行配置或记录遮挡前后的统计 / 照片。因此下文是静态路径解释，不是对那次对焦的运行归因。

## 已确认的结论

**二代 AF-S 的图像对焦路径可以独立继续，LiDAR 并非每次合焦的必要前置条件。** 哈苏专用混合策略在开始阶段先检查 PDAF 的有效性和方向分数，通过即可返回，不需要先通过 ToF 检查。方向阶段也按每个算法的有效性与分数收集候选，没有要求 ToF 必须成功才接受图像算法。

这为“遮挡后仍能准确对焦”提供了直接的软件机制。它不证明当时 LiDAR 完全无输出、不证明每次都是 PDAF 独立完成，也不能由此确定二代相对一代的精度提升各来自多少软件或硬件。

官方规格把二代 AF 类型列为 PDAF、CDAF、LiDAR，产品页说明 AF-S 有 425 个 PDAF 区域与 LiDAR 配合；这不是只有距离传感器的对焦系统。[官方规格](https://cdn.hasselblad.com/f/77891/x/15b206e1b9/x2d_ii_100c_datasheet_multi_20260416.pdf)、[官方产品页](https://www.hasselblad.com/x-system/x2d-ii-100c/)。

## 1. 确认使用哪套策略

配置 `hybrid.hybrid_policy = 1`；`global.af_alg_cfg` 启用 CDAF、PDAF、ToF，关闭 BDAF、LDAF、VDAF。

`hybrid_af_init` 在 `0x1ca448` 获取混合参数，`0x1ca44c` 读取策略字节，`0x1ca454` 调 `0x1c9a30` 的选择器。选择器在 `0x1c9a6c / 0x1c9a70` 检查值 1 并转到 `0x1c9acc`；这里读取 `0x719ac8–0x719af8` 的 GOT 项。解析 AArch64 GLOB_DAT / APS2 重定位后，七项确实指向哈苏专用策略，而非仅凭函数名推断。

| 阶段 | 回调入口 | 主要职责与本轮确认范围 |
| --- | --- | --- |
| start | `0x1d4eb0` | 调 CDAF 处理，检查各辅助算法的有效方向输出 |
| dir | `0x1d5248` | 收集有效候选，处理方向、峰值及范围 |
| peak | `0x1d7840` | 寻峰阶段；本轮锁定回调，未逐分支完整恢复 |
| check_peak | `0x1d91e8` | 按配置、候选分数、范围等检查 / 仲裁，具有失败返回路径 |
| goto_peak | `0x1da180` | 到位阶段，调 CDAF 处理；额外精修另受掩码门禁 |
| end | `0x1da848` | 收尾 |
| idle | `0x1da8c8` | 空闲 |

配置允许一些阶段在同一帧连续转移，因此不能把阶段数直接换算成固定帧延迟。运行配置是否被镜头 / 模式 / 服务覆盖未读回。

## 2. 不需要先等到 LiDAR 成功

start 中：

1. `0x1d4ef4` 把算法槽位置 1（PDAF），`0x1d4efc` 调 `alg_get_output_valid`。
2. 输出有效才读取句柄 `+0x2c`；`0x1d4f18–0x1d4f24` 将它与混合参数 `+0x100` 比较，满足后跳到 `0x1d5000`，最终返回 1。
3. PDAF 未通过才继续其他算法的同类检查；ToF 槽位 5 的检查在更后面的 `0x1d4fc8–0x1d4ff4`。
4. 都未通过则 `0x1d4ff8` 返回 0。这是该阶段结果，不等于整个 AF-S 已失败，后续由状态机处理。

结合字段与配置，`+0x2c` 是方向发布分数，门槛对应 `confirm_dir_conf = 100`；**这一步不是最终光学清晰度确认**。PDAF 先通过时尚未查询 ToF，这已经证明该阶段没有“必须有激光距离”的先决条件。

dir 在 `0x1d5418 / 0x1d5420` 按槽位查询有效性；`0x1d5434–0x1d5440` 检查方向分数，不合格就跳过该槽位。有效性 / 分数仲裁与“无条件相信 LiDAR”不同。

## 3. 二代的 PDAF AF-S 不只是一个门槛

`_exec_pdaf_afs_process` 位于 `0x1863f8`。已确认以下数据处理：

- **位置关联。** `0x186438` 调内部位置选择器 `0x185f08`。Type2 路径在 `0x185f24` 调 `get_pdaf_type2_align_lens_pos`（`0x14ff98`），不直接用当前运动中的镜头位置替代它。其他类型另有当前 / 上次位置选择。`0x186454` 将选定位置与离焦量相加形成峰值。对齐值的生产端与逐帧时间误差尚未完整追踪，不能把 getter 名称等同于已验证时序。
- **时间波动检查。** `0x18659c` 读取 `aaa_stddev_by_time_filter`；`0x1865c8–0x1865d0` 把时间标准差与镜头 fdelta 标尺乘参数的限值比较，超限可把高结果档位限制到 2。它是稳定性门禁证据，不是 Kalman 增益更新。
- **网格信息。** `0x18666c` 发布 mesh 峰值；`0x186944` 发布 mesh ROI。配置也包含 ROI 重叠权重、前景区域数量 / 连通性和位置范围惩罚。网格与目标 ROI 的证据比“固定取最强五区”更具体，但这些配置项各自的实际触发尚未全部恢复。
- **分档执行。** 结果跳转表 `0x6cb198` 将结果 3 导向 `0x186860`。这个分支限制峰值到镜头行程范围，发布峰值 / 范围 / 方向 / ROI，随后 `0x186968` 发绝对位置命令。该分支不查询 ToF，也没有直接调用方向扫描速度接口。整个混合系统在其他分支仍可扫描。

这些机制可以减少错误位置关联、波动测量造成的错误高档判定以及不必要行程；实际精度 / 耗时改善仍需要同场景验证。

二代配置的普通 PDAF 峰值分数依然是 **80**，最高档是 **120**；并不是把所有低档测量都提高到可直接接受。第一代先前的 80→100 试验没有复制二代的位置关联、分档与稳定性检查；一代 PDAF 的公开边界背景见 [PDAF 区域报告](../../../x2d/research/4.2.0/PDAF-425-BOUNDARIES.md)。

## 4. LiDAR 数据也要经过质量判断

配置选择 `TOF_ALGO_TYPE_DTOF_ADS6401`，实际代码入口为 `tof_dtof_ads6401_run`（`0x590220`）。不能用库中其他传感器 / 通用 Type1 的异常处理函数代替本机的运行证明。

这条 DTOF 路径会读取场景亮度 / 低光状态，也有结果降档和归零代码：`0x598094–0x5980a0` 在若干输入条件下把结果限制或置零；`0x5980a4` 读取低光状态，后续比较又会影响结果档位。结果表 `0x6d223c` 在 `0x59811c / 0x598124` 分派 0…3，各档位使用不同发布分数；异常档位路径 `0x598200` 将分数置零。`0x598c98` 发布 ToF 信息。

这证明 ToF 不是一个无条件有效的固定距离输入。**尚未证明“手遮挡”必然触发其中哪个条件**：手可能产生近距离回波、统计无效，也可能有残留历史值；需要运行统计才能确定。本文没有把某个尚未完整命名的字段硬解释成遮挡标志。

配置还有近距离、无效距离、更新超时和 mesh 置信阈值。它们是进一步定位的线索；仅看到这些数值还不足以说本轮已证明遮挡识别的全部实现。

## 5. CDAF 与末端精修须分开判断

start、dir、peak、goto 回调均存在 `cdaf_main_proc` 调用（`0x1d4ee0 / 0x1d53ac / 0x1d79a0 / 0x1da1bc`），且 CDAF 在配置中启用；peak 调用点于 2026-10-14 的追加离线核对中确认。因此图像反差路径存在，LiDAR 失效不会让其测量硬件一并失效。调用点存在不等于每次 AF-S 都经过全部阶段。

但是 `goto_peak.support_refine_peak = 1` **不等于每次到位都再做 CDAF 精修**。同一配置的 `goto_peak.enable_alg_mask` 六项全为 DISABLE。代码 `0x1da3d8–0x1da3e4` 按混合参数 `+0x180` 的对应位逐算法放行；掩码为零时这段精修循环跳过全部算法。除非运行时覆盖掩码，不能宣称该精修默认激活。

check_peak 还有独立的启用、次数、候选分数、机械范围与回差相关判断；`0x1d96ec–0x1d96fc` 检查候选区间。本轮没有把它们统称为“最终照片必定清晰”的光学证明，更没有证明二代准确源于始终执行末端 CDAF。

## 对第一代 X2D 的实际帮助与下一步

优先参考二代的 **测量与镜头位置关联、时间波动降档、ROI 内候选汇总、分档直达与失败回退**。这些方向与一代提升 AF-S 有关系，也可作为模拟库焦距 Kalman 的输入适配依据。增加 Kalman 不能代替输入标尺、时序或最后的合焦判断，本轮没有定位出它是二代优势来源。

硬件差异仍存在：二代有 425 个 PDAF 区域与 LiDAR；遮住 LiDAR 不会把二代的图像相位测量变成一代的 294 区输入。不能原样复制二代库、地址、Sony Type2 统计 ABI 或配置到一代。

若要确定遮挡时的真实路径，比较同镜头、同固件 / AF 点 / 目标、近远均重新起焦的成对事件；记录 PDAF / ToF 有效性、选中算法、最终位置和清晰度。静态研究可以继续定位各门禁及生产端，而真实收益的归因需要这些运行证据。本轮不要求先连接相机，也没有修改两代相机或桌面程序。

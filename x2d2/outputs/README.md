# X2D II 公开研究产物

这些目录保存本次公开的离线分析报告、函数反汇编、JSON 审计结果、Logo 预览和 AF-S / AF-C 图标资源。它们不是原始固件，也不是设备日志或安装包。

| 目录 | 内容 |
| --- | --- |
| `afs-without-lidar/` | AF-S 版本锁定审计结果 |
| `lidar-inspection-20261014/` | LiDAR / ToF / AF 链路审计和反汇编 |
| `startup-variants-20261014/` | 产品枚举、GUI 资源和启动 Logo 预览 |
| `display-inspection-20261014/` | 显示亮度、色彩 LUT 和 mura 相关审计 |
| `ibis-gps-inspection-20261015/` | IBIS 经纬度消息路径审计 |
| `focus-icons-20261015/` | 二代 AF-S / AF-C 原厂 SVG、PNG 和清单 |

所有输入固件均留在本地研究环境，工具通过 SHA-256 锁定输入版本；产物中的结论仍按静态分析、离线验证、用户反馈和待验证分别标注。

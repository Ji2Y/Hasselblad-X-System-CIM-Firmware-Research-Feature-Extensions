# 二代 AF-S / AF-C 原厂图标

来源：X2D II 100C，固件 1.3.16.2，system/bin/camera-gui 内嵌 Qt RCC 资源。

归属：二代对焦界面资源提取产物，放在 x2d2/outputs/focus-icons-20261015；与一代材料分开。

- svg/：10 张解压后的原始 SVG，内容未修改。
- png/：对应透明背景 PNG，按原始尺寸的 4 倍渲染，未改色。
- preview.png：深色背景对照预览；背景不属于原图标。
- manifest.json：固件与图标哈希、原资源路径及 PNG 尺寸。

包含控制界面 AF-S / AF-C、控制界面灰显、实时取景 AF-S / AF-C、实时取景灰显、取景模式标记，共 5 对。原始尺寸依次为 128×70、128×70、78×38、78×38、50×50。

校验：原 camera-gui SHA-256 锁定后，使用既有 Qt RCC 解析器读取资源并解压；SVG 做 XML 解析，PNG 检查内容和透明通道，压缩包校验 CRC 与清单哈希。未执行固件、未连接相机，未提交或推送。
